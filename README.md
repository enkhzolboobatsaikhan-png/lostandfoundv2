# МУИС Lost & Found — Refactored

Файлыг 3 үндсэн хэсэгт салгасан:

- `index.html` — HTML бүтэц
- `style.css` — дизайн, responsive UI
- `script.js` — Firebase + application logic

## Ажиллуулах

VS Code дээр энэ folder-ийг нээгээд `index.html`-ийг Live Server-ээр ажиллуул.

Firebase ашиглаж байгаа тул интернет холболт шаардлагатай.

## Анхаарах зүйл

Firebase Web config нь client-side application-д зориулагдсан config. Үндсэн хамгаалалт нь Firebase Authentication болон Firestore Security Rules дээр байх ёстой.
